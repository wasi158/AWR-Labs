# AWR Labs

Marketing site for AWR Labs — tech solutions, problem solving, and practical AI.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Notes

- Update `src/lib/site.ts` for domain, email, and social links.
- Brand assets live in `public/awr-labs-logo.png`.
